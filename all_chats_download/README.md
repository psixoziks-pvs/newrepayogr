# All Chats Download — плагин exteraGram

Плагин для [exteraGram](https://plugins.exteragram.app/) (SDK Elyx 1.4.4.3+,
Python 3.11 / Chaquopy, приложение exteraGram 12.5.1+).

## Что делает

Добавляет пункт **💾 «Скачать чат»** в меню «три точки» внутри чата или группы.
По нажатию выгружает всю доступную историю переписки в `.txt` файл и сохраняет
его в папку **«Загрузки»** на устройстве.

## Как работает

| Шаг | Реализация |
|---|---|
| Кнопка в меню | `get_chat_menu_items()` возвращает пункт 💾 с уникальным `hash` |
| Нажатие | Определяет открытый чат через `get_current_activity()` + `get_dialog_object()`, запуск фоновой выгрузки (UI не блокируется) |
| Сбор сообщений | История запрашивается пачками по ~100 сообщений (`ChatMessagesController.loadHistory`, `BATCH_SIZE = 100`); плюс подтяжка из локальной базы (`getAllMessages`) каждые 200 мс. Для каждого сообщения: дата, время, отправитель, текст; вместо медиа — пометки `[фото]`, `[видео]`, `[голосовое]`, `[стикер]`, `[документ]` и др. |
| Формат файла | Заголовок (Чат / Экспортировано / Всего сообщений / линейка) + строки `[2024-01-01 10:15] Иван: Привет` |
| Сохранение | Папка «Загрузки» (MediaStore Downloads, при недоступности — прямая запись в каталог Download + media scan). Имя: `chat_НазваниеЧата_2026-10-09.txt`, недопустимые символы → `_` |
| Уведомление | Диалог «Чат экспортирован, файл в Загрузках» с кнопками **«Открыть папку»** и **«ОК»** |
| Большие чаты | Счётчик «Загружено 500 / 12453» в диалоге прогресса + кнопка **«Отменить»**; страховочный таймаут 60 с на зависший ответ сервера |

## Пример выходного файла

```text
Чат: Название
Экспортировано: 2026-10-09 15:30
Всего сообщений: 12453
─────────────────────────────
[2024-01-01 10:15] Иван: Привет
[2024-01-01 10:16] Мария: Привет, как дела?
[2024-01-01 10:17] Иван: [фото]
```

## Установка

1. Откройте exteraGram → **Настройки → Плагины**.
2. Установите плагин из файла/архива (`.zip` с этой папкой) или подключитесь
   через Dev Server для разработки.
3. Зайдите в любой чат → меню «три точки» → **💾 Скачать чат**.

## Ограничения

Выгружается история, доступная аккаунту: локальный кэш + всё, что сервер
готов отдать по `messages.getHistory` (Telegram отдаёт историю в пределах
доступных лимитов аккаунта).
